查询编码与向量相似度

对应知识点：KP-RAG-003（必修 · 进阶）｜教学目标：说清文本如何编码为向量、相似度如何计算。

一、概念：文本怎么变成可比对的数字

编码器（如 Sentence-BERT，SRC-004）把一段文本映射为一个向量：语义相近的文本，向量方向相近。 检索时用余弦相似度衡量方向接近程度：

cos(q, d) = (q · d) / (|q| × |d|)，取值范围 [-1, 1]

注意两件事：余弦相似度可以取负值（方向相反，语义相反），不是 0 到 1； 相似度高只表示语义相近，不表示语义完全相同——“猫追狗”和“狗追猫”的向量可能很接近（SRC-004、SRC-003）。

二、交互：拖动查询向量，看检索排序怎么变

判断什么：查询向量靠近哪篇文档；能改什么：查询向量的 x、y 分量；观察什么：相似度表与最高亮文档；独立验证：让指定文档成为 top-1。

三、即学即测（ACT-S01-003）

题目：q = (1, 0)，d₁ = (0, 1)，d₂ = (−1, 0)。余弦相似度 cos(q, d₁) 与 cos(q, d₂) 分别是多少？

答案要点与解析

答案：B。

要点：cos(q, d₁) = (1×0+0×1)/(1×1) = 0（垂直，无关）；cos(q, d₂) = −1（方向相反）。 余弦相似度取值 [−1, 1]。

易错点：选 A 对应误区 MIS-RAG-003-02（以为取值范围是 0 到 1）； 认为“相似度高就是同一个意思”对应误区 MIS-RAG-003-01。
